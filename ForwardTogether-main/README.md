# Forward Together — Veteran Support Navigator

A senior capstone web application that helps veterans organize their mental-health support preferences and locate therapy, peer support, and official VA resources.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

## Architecture

- React + Vite frontend
- Guided, accessible support questionnaire
- Demo resource data for interface development
- Browser-local saved resources
- Optional Express/xAI backend scaffold in `server/`

## Important limitations

This application is a resource navigator, not a therapist or diagnostic tool. Demo provider listings must be replaced with results from trusted provider and location APIs before public use.

This independent student project is not affiliated with or endorsed by the U.S. Department of Veterans Affairs.
